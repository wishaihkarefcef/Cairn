# Cairn

Cairn is a Minecraft: Java Edition launcher for macOS, written in Swift, for personal use. It is not published, sold
or distributed, and its source code is not public.

It installs and launches Minecraft, plus Fabric mods and modpacks from [Modrinth](https://modrinth.com).

## No downloads

Cairn has no public releases, installers or download links, here or anywhere else. Anything offered as "Cairn" for
download, or any message asking you to sign in to Cairn, is not from this project. Don't run it or sign in to it.

## Microsoft sign-in

Cairn signs players in with their own Microsoft account so they can play Minecraft online:

- **Permission requested:** `XboxLive.signin` (and `offline_access` to stay signed in). Nothing else.
- **How:** players sign in on Microsoft's own page. Cairn never sees or stores passwords.
- **What it's used for:** obtaining Minecraft access through Microsoft's and Mojang's official services, to check
  that the account owns Minecraft and to start the game.
- **Where it's kept:** only on the player's own computer, in the system's secure credential storage.

## Privacy

Cairn collects no data and has no analytics or telemetry. It only contacts Microsoft, Xbox Live and Mojang (sign-in
and game files), Fabric (mod loader) and Modrinth (mods and modpacks).
